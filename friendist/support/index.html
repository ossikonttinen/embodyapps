Friendist – Tuki

Ota yhteyttä: hello@embodyapps.fi · vastaamme yleensä parin arkipäivän sisällä.

Missä tietoni ovat?

Vain puhelimessasi. Friendist ei käytä pilvipalvelua. Ota välillä varmuuskopio: Asetukset → Varmuuskopio ja siirto → Lataa tiedostona.

Miten siirrän tiedot uuteen puhelimeen?

Vanhassa puhelimessa: Asetukset → Varmuuskopio ja siirto → Lataa tiedostona (tai Kopioi leikepöydälle). Uudessa: Palauta tiedostosta (tai Liitä leikepöydältä).

Ostin Pron, mutta se ei näy

Avaa Pro-ikkuna ja valitse ”Palauta aiemmat ostot”. Varmista, että olet kirjautunut samalla Apple ID:llä kuin ostaessasi.

Miten peruutan tilauksen?

iPhonen Asetukset → oma nimesi → Tilaukset → Friendist. Pro on käytössä jakson loppuun asti.

Unohdin sovelluslukon PIN-koodin

Jos Face ID on käytössä, avaa sillä. Muuten koodia ei voi palauttaa, koska tiedot ovat vain laitteessasi. Valitse lukitusruudulla ”Unohdin koodin” → Tyhjennä tiedot, ja palauta sen jälkeen varmuuskopiosta.

Friendist – Support

Contact: hello@embodyapps.fi · we usually reply within a couple of working days.

Where is my data?

Only on your phone. Friendist uses no cloud service. Make a backup now and then: Settings → Backup and transfer → Download as file.

How do I move my data to a new phone?

On the old phone: Settings → Backup and transfer → Download as file (or Copy to clipboard). On the new one: Restore from file (or Paste from clipboard).

I bought Pro but it isn't showing

Open the Pro window and choose “Restore purchases”. Make sure you're signed in with the same Apple ID you bought with.

How do I cancel my subscription?

iPhone Settings → your name → Subscriptions → Friendist. Pro stays active until the end of the period.

I forgot my app lock PIN

If Face ID is on, use it. Otherwise the code can't be recovered, because your data exists only on your device. On the lock screen choose “Forgot code” → Clear data, then restore from a backup.
